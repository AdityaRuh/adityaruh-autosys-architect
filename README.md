# AutoSys Architect

Designs practical, production-ready system architectures and adapts them as requirements, scale, budget, and reliability constraints change.

This is a **Hermes agent package**. It installs into your Hermes home (`~/.hermes/` by default) and runs under the Hermes runtime from Nous Research.

## Install

1. Copy the env template and fill in required secrets:

   ```bash
   cp config/env.example .env
   $EDITOR .env
   ```

2. Validate before touching your Hermes home:

   ```bash
   ./checks/smoke-test.sh
   ```

3. Install:

   ```bash
   ./install.sh
   ```

4. Messaging channels were not configured. Skip:

   ```bash
   hermes gateway setup
   ```

5. Start chatting:

   ```bash
   hermes profile use autosys-architect
   hermes
   ```

## First run

- `hermes skills list` — confirm 13 baseline skill(s) loaded.
