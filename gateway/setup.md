# Gateway setup — AutoSys Architect

AutoSys Architect ships as a **CLI-only MVP**. No external messaging or gateway platforms are configured in this package.

## MVP status

- **Supported interaction model:** local or VPS CLI sessions only
- **External gateway platforms:** none configured
- **Chat DM policy:** not applicable in MVP
- **Chat slash commands:** not available in MVP
- **Voice/media gateway features:** not available in MVP

## What to do for MVP

No gateway setup is required.

Use the agent through the Hermes CLI/runtime entrypoints documented in the package README and install flow.

## Configured platforms

None.

## Future Hermes reference — not part of shipped MVP behavior

Hermes can support messaging gateways in broader deployments, but that functionality is **not configured, enabled, or promised by this AutoSys Architect MVP package**.

If a future version adds a gateway platform, it must be treated as a new scoped capability with its own approved product and technical requirements, including conservative access controls.
